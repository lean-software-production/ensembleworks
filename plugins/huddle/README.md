# Huddle

Huddle owns LiveKit call credentials and the browser media session. Configure
`livekitUrl`, `livekitApiKey`, and `livekitApiSecret` in the Huddle plugin,
then use **Join huddle** from a thread header. Canvas has no LiveKit settings,
token RPC, or media dependency.

The default room is `bb-huddle`; operators can change it in Huddle settings.
